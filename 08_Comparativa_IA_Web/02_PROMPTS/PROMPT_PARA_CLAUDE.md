# Prompt para Claude

Voy a adjuntar una fuente maestra y cinco imágenes de Serenamente.

Actúa como director creativo digital, diseñador de experiencia y desarrollador frontend senior. Diseña y construye una página web institucional completa para Serenamente.

Lee primero `FUENTE_MAESTRA_SERENAMENTE.md` y utiliza las cinco imágenes adjuntas. No te mostraré ninguna página anterior porque quiero que desarrolles una propuesta auténticamente independiente.

Tienes libertad creativa completa. No me pidas que elija colores, tipografías o estilo antes de comenzar. Inventa una dirección visual propia, ambiciosa y profesional que responda al objetivo de la marca.

Requisitos:

1. Crea el concepto y luego desarrolla la página completa.
2. Usa las cinco imágenes de manera inteligente y con funciones distintas.
3. Prioriza impacto inicial, claridad, emoción, navegación intuitiva y experiencia móvil.
4. Incluye movimiento o interacción cuando aporte valor y respeta `prefers-reduced-motion`.
5. Usa HTML semántico, CSS y JavaScript funcional.
6. Entrega todos los archivos completos, no fragmentos ni pseudocódigo.
7. Si Claude permite crear un artefacto o archivos descargables, utilízalo.
8. No despliegues la página.
9. Explica al final el concepto creativo y los datos que requieren confirmación.

Tu propuesta competirá con diseños independientes creados por Gemini y Codex. No copies estilos genéricos de bienestar ni recurras automáticamente a colores pastel, tarjetas redondeadas o plantillas típicas. Sorpréndeme con una solución coherente y realizable.
