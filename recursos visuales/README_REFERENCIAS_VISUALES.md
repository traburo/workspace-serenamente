# Recursos visuales de Serenamente

Esta carpeta reúne fotografías, videos, logos, códigos QR y referencias disponibles. Es una biblioteca opcional, no una fuente estética obligatoria.

## Cuándo utilizarla

- Cuando el usuario solicita expresamente usar activos existentes.
- Cuando una pieza necesita demostrar una experiencia real o identificar oficialmente a Serenamente.
- Cuando un recurso concreto aporta autenticidad, reconocimiento o información útil.

No es necesario inspeccionar esta carpeta antes de formular una dirección creativa nueva. Un encargo comercial puede comenzar desde un lienzo completamente libre.

## Criterio creativo

- Ningún activo define por sí solo una paleta, tipografía, composición o estilo universal.
- Las referencias pueden usarse, reinterpretarse, combinarse selectivamente o no utilizarse.
- Las decisiones visuales responden al objetivo, público, canal, contexto y experiencia buscada en cada encargo.
- SER-BCS-01 es un antecedente histórico obsoleto y solo se consulta por solicitud explícita de reproducción, estudio o comparación histórica.

## Controles obligatorios

Antes de publicar un activo, verificar:

1. veracidad y vigencia de datos, enlaces y códigos QR;
2. seguridad de participantes y públicos;
3. legalidad y privacidad;
4. licencias, autorías y autorizaciones de imagen, especialmente si aparecen menores;
5. accesibilidad en el formato final.
