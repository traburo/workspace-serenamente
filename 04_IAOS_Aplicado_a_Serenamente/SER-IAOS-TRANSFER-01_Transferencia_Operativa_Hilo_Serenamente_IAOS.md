### 7.5 Sobre sistema comercial

Decision estrategica:

No basta con crear contenido, anuncios o agentes. Serenamente necesita un sistema comercial operativo minimo para registrar, confirmar, recordar, medir y dar seguimiento.

Flujo definido:

`Atencion -> Interes -> Registro -> Pago o reserva -> Confirmacion -> Recordatorio -> Asistencia -> Seguimiento -> Continuidad`

Herramientas candidatas:

- Railway: backend/base/API.
- Resend: correos transaccionales.
- Base de datos: PostgreSQL u otra opcion a definir.
- Pago: transferencia, link externo, Flow, Mercado Pago, Webpay/Transbank u otra pasarela.
