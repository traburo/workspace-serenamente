# Paquete de activación — Agente de Contenido Comercial Serenamente

## Condición del paquete

Instrumento operativo IAOS. No es un documento normativo SER, no modifica el Método Serenamente y no autoriza publicaciones, ofertas ni promesas comerciales.

Versión operativa: 1.0  
Fecha: 13 de julio de 2026  
Uso: producción de borradores comerciales sujetos a revisión humana.

## Propósito

Permitir que un agente de inteligencia artificial produzca contenido comercial coherente con Serenamente, conectado con una oferta y un objetivo medible, sin inventar identidad, metodología, evidencia, precios o aprobaciones.

## Archivos del paquete

1. `01_PROTOCOLO_OPERATIVO.md` — misión, fuentes, proceso, límites y control de calidad.
2. `02_PROMPT_SISTEMA.md` — instrucciones listas para activar el agente.
3. `03_BRIEF_DE_TAREA.md` — plantilla mínima para solicitar una pieza o campaña.
4. `04_PRUEBA_CONTROLADA.md` — primera prueba interna con criterios de aprobación.
5. `Referencias/` — videos de referencia y plantillas de adaptación para Serenamente.

## Orden de uso

1. Cargar `02_PROMPT_SISTEMA.md` como instrucción principal.
2. Entregar al agente los documentos indicados por el protocolo según la tarea.
3. Completar `03_BRIEF_DE_TAREA.md`.
4. Revisar la salida con el checklist del protocolo.
5. Obtener validación humana antes de publicar, enviar o activar campañas.

## Regla de precedencia

Los documentos SER vigentes prevalecen sobre cualquier documento IAOS, propuesta o instrucción comercial. Los documentos operativos ayudan a producir; no pueden redefinir identidad, método ni evidencia.
