# IAOS - Sistema Operativo de Arquitectura Inteligente

Paquete documental madre v1.0 en formato Markdown.

IAOS es un sistema creado por Alex para recibir, diagnosticar, ordenar y activar proyectos mediante inteligencia artificial, documentacion, produccion comercial, contenido, agentes especializados y trazabilidad operativa.

## Documentos

1. `IAOS-BASE-01_Arquitectura_Fundacional_del_IAOS.md`
   Define que es IAOS, su naturaleza multi-proyecto, su rol como meta-agente y sus principios fundacionales.

2. `IAOS-ING-01_Modelo_de_Ingesta_y_Diagnostico_de_Proyectos.md`
   Define como IAOS recibe un proyecto nuevo, que datos pide, como diagnostica y como propone primeros pasos.

3. `IAOS-OP-01_Protocolo_Operativo_de_Trabajo_con_IA.md`
   Define como debe trabajar una IA con Alex bajo IAOS: ejecutar, clasificar, preguntar, advertir y derivar a subagentes.

4. `IAOS-PROD-01_Sistema_de_Produccion_Comercial_y_Contenido.md`
   Define como IAOS convierte un proyecto en piezas comerciales, contenido, campanas, landing pages y automatizaciones.

5. `IAOS-GOV-01_Gobernanza_Autoridad_y_Trazabilidad.md`
   Define autoridad, estados, trazabilidad, limites, versiones y reglas para no mezclar proyectos.

6. `IAOS-SER-01_Aplicacion_del_IAOS_a_Serenamente.md`
   Define Serenamente como primer caso profundo de aplicacion del IAOS, sin confundirlo con el IAOS madre.

## Uso rapido

- Para entender el sistema completo: leer `IAOS-BASE-01`.
- Para recibir un proyecto nuevo: usar `IAOS-ING-01`.
- Para trabajar con una IA en tareas concretas: usar `IAOS-OP-01`.
- Para crear contenido o activos comerciales: usar `IAOS-PROD-01`.
- Para resolver autoridad, estados o trazabilidad: usar `IAOS-GOV-01`.
- Para trabajar con Serenamente: usar `IAOS-SER-01`.

## Estado

Esta es una primera version fundacional. No modifica documentos existentes de Serenamente ni aprueba documentos previos. Organiza IAOS como sistema madre independiente y aplicable a multiples proyectos.
