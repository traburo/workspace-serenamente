# Respuesta de prueba

Se revisarán únicamente las fotografías y variantes de logo pertinentes al encargo. Antes de seleccionar imágenes se comprobarán las autorizaciones de publicación, con especial cuidado cuando aparezcan participantes o menores. El logo se utilizará como identificador auténtico, no como obligación para derivar el resto de la estética.

La campaña mantiene libertad para definir composición, color, tipografía, ritmo y movimiento desde su objetivo comercial. Cada activo se incluirá porque cumple una función concreta, no porque pertenezca a una carpeta previa.
