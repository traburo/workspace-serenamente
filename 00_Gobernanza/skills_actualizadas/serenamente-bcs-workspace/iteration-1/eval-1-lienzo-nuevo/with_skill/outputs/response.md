# Respuesta de prueba

La propuesta comenzará desde un lienzo en blanco. Primero se definirá la experiencia que debe provocar la página, el público, la acción principal y el contexto digital; después se explorarán direcciones conceptuales sin heredar paleta, tipografía, composición ni componentes de páginas anteriores. No se revisarán las fotografías existentes porque el encargo no las necesita.

Antes de considerarla publicable se comprobarán datos y afirmaciones, seguridad, legalidad, derechos y privacidad, además de contraste, navegación, legibilidad, movimiento reducible y experiencia móvil.
